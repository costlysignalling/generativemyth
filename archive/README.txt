GENERATIVE MYTH — OFFLINE ARCHIVAL EDITION

Open GenerativeMyth.html directly in a web browser. No installation, local
server, network connection, remote font, CMS, database, or R runtime is needed.

The HTML file contains the complete interface, recursive drawing engine, Czech
and English myth generator, styles, and required JavaScript.

SHA256SUMS.txt records the file's SHA-256 checksum. It can be used to verify
that the archival copy has not changed or become corrupted.

For long-term preservation, keep this entire folder together with the project
source code and maintain copies on several independent storage media.
